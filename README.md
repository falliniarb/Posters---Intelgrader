# IntelGrader Poster Studio

1. Open `index.html` in Chrome, Edge, or Safari.
2. Enter the institute name.
3. Click **Download poster** to save a WhatsApp-ready PNG.

The current template is the IntelGrader welcome poster. To add a future template, place its 1122 × 1402 base image in `assets/` and add it to the `templates` list in `index.html`.
